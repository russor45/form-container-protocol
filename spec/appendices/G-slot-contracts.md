## Appendix G: Slot Contract Table

| Slot            | Required: Yes/No | ARIA Role / Landmark                                                               | Behavioral Guarantees                                                                                                                | Content Guidelines                                                     |
| --------------- | -------- | ---------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------- |
| `header`        | ❌ No       | `role="heading"` (with `aria-level` appropriate to context)                        | Always rendered at the top of the container when present. Should receive focus on open if no other element is auto-focused.         | Title text, optional description, and optional close button.           |
| `body`          | ✅ Yes      | `role="region"` or implicit sectioning element                                     | Scrollable if content exceeds container height. Must preserve form semantics (`<form>` element or equivalent).                       | Form fields, grouped logically with labels and instructions.           |
| `footer`        | ❌ No       | `role="contentinfo"` or `role="region"`                                            | Always rendered after `body` when present. Should contain at least one primary action (submit) and may contain secondary actions.    | Action buttons, links, or other form submission controls.              |
| `notifications` | ❌ No       | `role="status"` (for non-blocking updates) or `role="alert"` (for blocking errors) | Dynamically updated based on submission results. Must be programmatically focusable for screen readers when populated.               | Inline status messages, validation summaries, or global error notices. |
